# Ассеты бренда

- `fonts/brand_font.ttf` — шрифт для заголовка на картинке. Уже вшит в проект
  (PT Sans, поддерживает кириллицу, лицензия SIL Open Font License). Можно
  заменить на свой — просто положи другой `.ttf` сюда же или укажи другой
  путь в `BRAND_FONT_PATH`.
- `logo.png` — логотип канала, PNG с прозрачным фоном. Тут его нет — код и
  без него работает нормально, просто логотип не накладывается, пока файл
  не появится.

Остальные настройки бренда — в `brand_config.py` (или переменных окружения `BRAND_*`).

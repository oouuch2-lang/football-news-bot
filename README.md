# Бот_админ_футбол

Бот, который сам следит за спортивными RSS-лентами, переписывает новость
по-русски, генерирует к ней фотореалистичную картинку в едином стиле
канала и публикует готовый пост (картинка + текст, без ссылок на
источник) в Telegram-канал. Работает бесплатно — запускается по
расписанию через GitHub Actions, без своего сервера.

**Важные требования к каналу, зашитые в код:**
- Посты **только на русском**. Без ключа Gemini бот вообще ничего не
  публикует (см. раздел 5) — английского запасного варианта нет
  намеренно.
- Картинки — **фотореалистичные**, не рисованные и не мультяшные (это
  задано в промпте для ИИ-генератора).
- **Никаких ссылок** на источник в посте.

## Как это устроено

- `config.py` — все настройки бота (токен, канал, RSS-ленты, провайдер картинок).
- `brand_config.py` — бренд-бук: цвета, шрифт, логотип, стиль картинок.
- `bot_settings.py` — настройки, которые можно поменять перепиской с ботом (см. ниже), хранятся в `data/settings.json` и перекрывают дефолты из `config.py`/`brand_config.py`.
- `gemini_client.py` — общий вызов Gemini API, использует `text_rewriter.py` и `admin_agent.py`.
- `news_parser.py` — читает RSS-ленты, отсеивает уже опубликованные новости.
- `text_rewriter.py` — переписывает текст новости через Gemini (живо, по-русски, без канцелярита). Без ключа `GEMINI_API_KEY` — новость не публикуется вообще (см. раздел 5 настройки), а не публикуется оригиналом с RSS.
- `image_generator.py` — генерирует картинку через Pollinations / Hugging Face / Cloudflare.
- `image_processor.py` — накладывает на картинку заголовок и логотип.
- `main.py` — всё это связывает и публикует пост в канал. Запускается по расписанию (`.github/workflows/telegram_bot.yml`, раз в час) или вручную.
- `avatar_manager.py` — генерирует и ставит новую аватарку канала. Запускается по расписанию (`.github/workflows/avatar.yml`, раз в неделю) или вручную.
- `stats.py` — считает посты за неделю и присылает сводку в личку. Запускается только вручную (`.github/workflows/stats.yml`).
- `admin_agent.py` — переписка с владельцем в личке: понимает задачу через Gemini, предлагает варианты, применяет выбранное. Запускается по расписанию (`.github/workflows/admin_chat.yml`, каждые 5 минут).
- `data/published_history.json` — ссылка → время публикации для уже опубликованных новостей (создаётся автоматически).
- `data/settings.json`, `data/admin_state.json` — изменённые через переписку настройки и служебное состояние диалога (создаются автоматически).

## Живых кнопок в Telegram нет, зато есть переписка с ботом

Настоящий Telegram-инлайн-кнопки (нажал — бот сразу отреагировал) нужен
постоянно включённый процесс — GitHub Actions так не умеет, он «включился,
сделал дело, выключился». Вместо кнопок — переписка в личке с ботом:
он проверяет новые сообщения от владельца (`ADMIN_CHAT_ID`) каждые 5 минут
(`admin_agent.py`, workflow `admin_chat.yml`), понимает задачу через Gemini,
предлагает 2-3 конкретных варианта и после ответа номером сам применяет
выбранное — правит `data/settings.json` (цвета, стиль картинок, тон текста,
частоту публикаций, RSS-ленты) или сразу меняет аватарку канала. Задержка
до 5 минут вместо мгновенной реакции — цена того, что всё это бесплатно и
не требует своего сервера. Репозиторий поэтому публичный — на публичных
репозиториях у GitHub Actions нет лимита минут в месяц, иначе проверка
раз в 5 минут быстро съела бы бесплатную квоту приватного репозитория.

Более того — прямо в чате с ботом есть настоящее меню с кнопками
Telegram: напиши `/start`, `меню` или `кнопки`, и придёт сообщение с
четырьмя кнопками:

- **📰 Опубликовать новости сейчас** — сразу проверяет ленты и постит, что нашлось.
- **🖼 Сменить аватарку** — сразу генерирует и ставит новую аватарку.
- **📊 Статистика** — присылает сводку за 7 дней.
- **🎨 Оформление / тон / ленты** — подсказывает, как начать переписку про настройки.

Нажатие кнопки обрабатывается тем же опросом раз в 5 минут, что и
сообщения, — задержка та же (до ~5 минут).

Всё это дублирует ручные запуски на вкладке **Actions** (кнопка
**Run workflow**) — они никуда не делись, это просто более быстрый путь
из самого Telegram:

| Действие | Кнопка в чате | Или вручную на GitHub |
|---|---|---|
| Опубликовать новости прямо сейчас | 📰 Опубликовать новости сейчас | Actions → Публикация спортивных новостей → Run workflow |
| Сменить аватар | 🖼 Сменить аватарку | Actions → Смена аватарки канала → Run workflow |
| Статистика в личку | 📊 Статистика | Actions → Статистика канала → Run workflow (нужен `ADMIN_CHAT_ID`) |
| Оформление, тон текста, частота/ленты | 🎨 Оформление / тон / ленты → дальше просто пиши текстом | Правка `data/settings.json` вручную |

## Про сервисы, которые НЕ подключены

Часть сервисов из исходного списка задачи сюда не попала:

- **Stockio** — у него нет REST API (только сайт для ручного скачивания), несмотря на заявленное.
- **tteg, FreeTheAi** — реальные штуки, но это самодельные прокси одного разработчика поверх чужих API (Unsplash, OpenAI и т.п.), без официального статуса. Для бота, который должен работать без присмотра, это риск: может отвалиться или забаниться в любой момент.
- **Agnes AI** — при проверке нашёлся пакет специально под ИИ-агентов с подозрительно навязчивым продвижением. Не подключал.
- **Goblin AI** — самодельный пакет от независимого разработчика, тот же риск, что и выше.

Вместо них — только официальные бесплатные тарифы: Pollinations (без
ключа), Hugging Face, Cloudflare Workers AI, и теперь Gemini API от
Google — для текста.

## Про «режим экономии»

Отдельный механизм «бот сам видит, что подходит к лимиту API, и снижает
частоту» не делал. У бесплатных тарифов лимиты негласные и часто меняются —
подгонять код под конкретные цифры значит, что при первом же их изменении
логика сломается. Вместо этого у бота и так есть защита на каждый случай:
не получилось сгенерировать картинку — публикует без неё; не получилось
переписать текст — публикует оригинал; не получилось опубликовать пост —
пробует на следующем запуске. Практический эффект тот же, без хрупких
предположений о точных лимитах.

## Настройка с нуля

### 1. Создать бота и канал в Telegram

1. Напиши в Telegram [@BotFather](https://t.me/BotFather), команда `/newbot`, следуй подсказкам — получишь токен вида `123456:AAExample...`.
2. Создай канал (или используй существующий), добавь туда бота **администратором** (с правом публиковать сообщения).
3. Узнай ID канала — это может быть `@username_канала` (если канал публичный) или числовой ID (если приватный, вида `-1001234567890`).

### 2. Настроить проект локально (по желанию, для проверки перед выкладкой)

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`: `TELEGRAM_TOKEN`, `CHANNEL_ID`, `RSS_URLS` (ссылки на RSS-ленты через запятую).

Проверить, что всё работает:

```bash
python main.py
```

### 3. Выбрать способ генерации картинок

По умолчанию используется **Pollinations AI** — работает вообще без ключа, ничего не нужно настраивать.

Если хочешь другой вариант:

- **Hugging Face** — зарегистрируйся на [huggingface.co](https://huggingface.co), возьми токен в настройках профиля (Access Tokens), впиши в `HUGGINGFACE_API_KEY`, поставь `IMAGE_PROVIDER=huggingface`.
- **Cloudflare Workers AI** — нужен `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` из личного кабинета Cloudflare, `IMAGE_PROVIDER=cloudflare`.
- **Без картинок** — `IMAGE_PROVIDER=none`, посты будут только текстовые.

Если провайдер недоступен или лимит исчерпан — бот сам публикует новость без картинки, ничего не падает.

### 4. Настроить бренд-стиль канала

В `brand_config.py` (или через переменные `BRAND_*`) задай свои цвета и стиль картинок.
Логотип и шрифт — необязательны:

- Положи логотип (PNG с прозрачным фоном) в `assets/logo.png`.
- Положи шрифт (`.ttf`) в `assets/fonts/brand_font.ttf`.

Если файлов нет — бот просто не накладывает логотип и рисует заголовок стандартным шрифтом.

Стиль картинок (`BRAND_IMAGE_STYLE`) настроен на фотореализм — промпт явно
запрещает рисованный/мультяшный стиль. У бесплатного генератора (Pollinations)
нет фиксации сида, поэтому изредка (по тестам — примерно 1 раз из 3-4)
картинка выходит не по теме или странной — это особенность бесплатного
сервиса, не баг; переделывать вручную не нужно, следующий пост будет нормальным.

### 5. Живой текст постов через Gemini — ОБЯЗАТЕЛЬНЫЙ шаг

Канал русскоязычный, а RSS-ленты, которые реально работают, — английские
(рабочих русскоязычных RSS по футболу на момент настройки не нашлось).
Без ключа
Gemini бот молча не публикует вообще ничего — не потому что сломан, а
потому что английские посты в этом канале запрещены по требованию, и
переводить их больше нечем.

1. Зайди на [aistudio.google.com/apikey](https://aistudio.google.com/apikey), войди аккаунтом Google.
2. Нажми **Create API key** — ключ бесплатный, карта не нужна.
3. Впиши в `GEMINI_API_KEY`.

### 6. Твой Telegram ID — нужен для статистики и для переписки с ботом

Узнай свой Telegram ID: напиши боту [@userinfobot](https://t.me/userinfobot),
он пришлёт в ответ числовой ID. Впиши в `ADMIN_CHAT_ID`.

Без этого шага `stats.py` просто не сможет написать тебе в личку, а
`admin_agent.py` (переписка про оформление, аватарку, тон текста,
частоту — см. раздел «Живых кнопок в Telegram нет») не будет отвечать
вообще никому, даже тебе — так и задумано: бот должен знать, что это
пишет владелец, а не случайный человек (репозиторий публичный, имя
бота в коде видно всем).

### 7. Выложить на GitHub и включить автозапуск

1. Создай репозиторий на GitHub и залей туда код (файл `.env` заливать **не нужно** — он и так в `.gitignore`).
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret** — добавь:
   - `TELEGRAM_TOKEN`
   - `CHANNEL_ID`
   - `RSS_URLS`
   - при необходимости: `HUGGINGFACE_API_KEY`, `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`, `GEMINI_API_KEY`, `ADMIN_CHAT_ID`
3. Там же на вкладке **Variables** можно (не обязательно) добавить настройки бренда (`BRAND_PRIMARY_COLOR` и т.д.), `IMAGE_PROVIDER` и `GEMINI_MODEL`, если не хочешь дефолт.
4. Перейди во вкладку **Actions** репозитория и включи все три workflow (публикация новостей, смена аватарки, статистика) — дальше бот работает сам: новости каждый час, аватарка раз в неделю по понедельникам.
   Запустить любой из них вручную можно там же кнопкой **Run workflow**.

## Важно про бесплатный режим

- GitHub Actions на публичных репозиториях бесплатен без ограничений по времени; на приватных — есть бесплатный лимит минут в месяц.
- Расписание `cron` в GitHub Actions — не поминутно точное, при высокой нагрузке GitHub может задержать запуск на несколько минут.
- Pollinations и бесплатные тарифы Hugging Face/Cloudflare могут иметь лимиты по количеству запросов в день — при превышении бот просто опубликует новость без картинки.
